# 🤖 Gemini AI Powered Group Tagger Bot

An advanced Telegram Group Mention and AI Assistant bot built with Pyrogram and Google GenAI SDK.

## 🚀 Features
- ⚡ 7+ Custom Tagging Commands (`/tagall`, `/vctag`, etc.)
- 🧠 Gemini AI Smart Responses on Mention/Reply
- ⏸️ Pause, Resume, and Stop controls for Admins
- 🔒 Secure Configuration via Environment Variables

## 🛠️ Deployment Vars
Configure these variables in your hosting dashboard:
- `API_ID` & `API_HASH` (Get from my.telegram.org)
- `BOT_TOKEN` (Get from @BotFather)
- `GEMINI_API_KEY` (Get from Google AI Studio)
- `OWNER_ID` (Your Telegram Account ID)
- `UPDATES_LINK` & `SUPPORT_LINK` (Your links for buttons)
